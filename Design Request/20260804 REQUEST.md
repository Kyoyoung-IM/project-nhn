- 발견 위치: `define`, 터렛 판매 규칙
- 이슈: 설치 터렛 판매 시 누적 구매가에서 반환할 비율을 나타내는 필드가 최신 기준 데이터 테이블에도 없다.

- 영향: Tier 2 이상 터렛도 데이터의 `basePrice=-1`을 사용하지 않고 실제 투입된 전체 구매 비용의 절반을 반환한다.
