# Bundled font

## Noto Sans KR

- File: `NotoSansKR.ttf`
- Source: https://github.com/google/fonts/tree/main/ofl/notosanskr
- Copyright: The Noto Project Authors
- License: SIL Open Font License 1.1 (`OFL.txt`)
- Usage: Korean and Latin game UI text in desktop and Web builds
- Modification: The upstream variable font file was downloaded without modification and renamed for a stable Godot resource path.

The upstream `METADATA.pb` and full `OFL.txt` are stored beside the font file.
