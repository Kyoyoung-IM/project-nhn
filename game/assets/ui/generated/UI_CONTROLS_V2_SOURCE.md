## 배속 캡슐

캐주얼 판타지 광산 디펜스 게임의 우측 상단에 배치할 3:1 비율의 캡슐형 버튼이다. 짙은 남색 외곽 프레임, 따뜻한 금색 본체, 작은 황동 리벳을 사용하고 중앙은 코드에서 배속 기호를 표시할 수 있도록 비워 둔다. 보석, 문자, 화살표, 워터마크는 넣지 않는다.

## 일시정지 버튼

동일한 UI 스타일의 단순한 원형 버튼이다. 짙은 남색 본체와 하나의 금색 외곽선만 사용하며, 중앙에 동일 크기의 크림색 세로 막대 두 개를 이미지 요소로 포함한다. 리벳, 보석, 문자, 추가 장식, 워터마크는 넣지 않는다.
