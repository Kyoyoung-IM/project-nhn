# 생성형 UI 에셋 기록

- 생성일: 2026-08-05
- 생성 도구: OpenAI 내장 이미지 생성 도구
- 용도: 일반 플레이 상점 카드, 상점 제어판, 배속·일시정지 버튼, 옵션 모달 스킨
- 적용 범위 제외: 테스트 옵션 및 데이터테이블 편집 UI
- 생성 방식: 승인된 UI 디자인 보드를 스타일 참조로 사용하고, 단색 마젠타 크로마키 배경으로 개별 에셋을 생성한 뒤 로컬 후처리로 투명 PNG를 제작함
- 권리·출처: OpenAI 생성 결과물. 외부 이미지 에셋을 직접 포함하지 않음

## 공통 프롬프트 요약

캐주얼 2D 판타지 게임 UI, 짙은 남색 석재·도색 금속 프레임, 따뜻한 금색 테두리, 단순한 명암과 굵은 외곽선을 사용한다. 보석·수정·다이아몬드·육각형 보석 장식을 사용하지 않으며 재화 표시는 둥근 금화로 통일한다. 글자·숫자·로고·워터마크 없이 `#ff00ff` 단색 크로마키 배경에 분리된 UI 오브젝트만 생성한다.

## 에셋별 요청

- `shop_card_frame_v1.png`: 306×270에 맞는 가로가 조금 긴 카드 프레임. 상단 본체 영역, 나무 이름 띠, 둥근 금화가 포함된 가격 캡슐로 구성.
- `shop_controls_panel_v1.png`: 카드와 같은 높이. 상단 35%는 금화와 보유 골드 영역, 하단 65%는 큰 중앙 리롤 픽토그램과 런타임 비용 문구 공간으로 구성.
- `speed_capsule_v1.png`: 런타임 배속 글리프를 담는 금색 캡슐 버튼.
- `pause_button_v1.png`: 크림색 일시정지 글리프가 포함된 남색 원형 버튼.
- `options_panel_v1.png`: 크림색 내부와 네 개의 색상별 버튼 영역을 가진 520×800 옵션 모달.

최종 생성 원본은 Codex 로컬 생성 이미지 보관소에서 제작했으며, 게임에서는 이 폴더의 투명 PNG만 참조한다.
