## 공통 프롬프트 요약

캐주얼 2D 판타지 게임 UI, 짙은 남색 석재·도색 금속 프레임, 따뜻한 금색 테두리, 단순한 명암과 굵은 외곽선을 사용한다. 보석·수정·다이아몬드·육각형 보석 장식을 사용하지 않으며 재화 표시는 둥근 금화로 통일한다. 글자·숫자·로고·워터마크 없이 `#ff00ff` 단색 크로마키 배경에 분리된 UI 오브젝트만 생성한다.

## 에셋별 요청

- `shop_card_frame_v1.png`: 306×270에 맞는 가로가 조금 긴 카드 프레임. 상단 본체 영역, 나무 이름 띠, 둥근 금화가 포함된 가격 캡슐로 구성.
- `shop_controls_panel_v1.png`: 카드와 같은 높이. 상단 35%는 금화와 보유 골드 영역, 하단 65%는 큰 중앙 리롤 픽토그램과 런타임 비용 문구 공간으로 구성.
- `speed_capsule_v1.png`: 런타임 배속 글리프를 담는 금색 캡슐 버튼. v2 적용 후 2026-08-07에 런타임 파일을 제거했다.
- `pause_button_v1.png`: 크림색 일시정지 글리프가 포함된 남색 원형 버튼. v2 적용 후 2026-08-07에 런타임 파일을 제거했다.
- `options_panel_v1.png`: 크림색 내부와 네 개의 색상별 버튼 영역을 가진 520×800 옵션 모달.
- `game_over_title_v1.png`: 패배 화면 중앙에 사용하는 `GAME OVER` 일러스트 타이틀. 현재 게임 UI의 짙은 남색·금색 팔레트와 굵은 외곽선을 유지하면서 미세 장식과 명암 단계를 줄인 단순한 캐주얼 RPG 스타일로 생성했다. 글자는 런타임 폰트가 아니라 이미지 안에 문자 형태로 직접 그려져 있다.
- `game_clear_title_v1.png`: 승리 화면 중앙에 사용했던 `GAME CLEAR` 일러스트 타이틀. v2 적용 후 2026-08-07에 런타임 파일을 제거했다. `GAME OVER`와 유사한 굵고 둥근 2단 입체 구조를 유지하면서 밝은 샴페인 골드·백금색 하이라이트와 시트린·투명 수정 장식으로 승리 화면을 구분했다. 글자는 런타임 폰트가 아니라 이미지 안에 문자 형태로 직접 그려져 있다.
- `game_clear_title_v2.png`: 승리 화면 중앙에 사용하는 `GAME CLEAR!` 일러스트 타이틀. 기존 금색·갈색 아웃라인을 유지하면서 글자 내부를 주황 계통으로 낮추고, 명암 단계와 주변 보석 묘사를 단순화해 과도한 밝기를 줄였다.
