# NAN 2026 공모전 및 제출 지침

이 문서는 공모전 일정 확인, 제출물 제작, 링크 검증과 권리·라이선스 관리에 적용한다.

## 공식 정보

- 공식 사이트: https://nan2026.nhn.com/
- 참가 약관: https://nan2026.nhn.com/terms
- 모집 및 사전 과제 제출 기간: 2026-07-10 ~ 2026-08-10
- 참가 팀 발표: 2026-08-22
- 본행사: 2026-09-04 ~ 2026-09-06, NHN 판교 사옥에서 48시간 전일 참여
- 참가 자격: 만 19세 이상, 개인 또는 최대 3인 팀
- 사전 과제 심사 후 본선 10팀을 선발한다.
- 일정과 운영 규정은 바뀔 수 있으므로 제출 직전에 공식 페이지와 약관을 다시 확인한다.
- 공개된 정량 심사 배점은 확인되지 않았으므로 추측하지 않는다.

## 필수 제출물

1. 플레이 가능한 Web 빌드와 전체 소스
   - 링크 클릭만으로 브라우저에서 실행 가능해야 한다.
   - PC 실행 파일 직접 제출을 전제로 하지 않는다.
   - 전체 소스를 같은 저장소에 포함하고 커밋 기록을 유지한다.
2. 30~60초 실제 플레이 영상
   - YouTube 공개 또는 일부 공개 링크를 사용한다.
   - 플레이 화면을 AI로 조작하거나 합성하지 않는다.
3. 게임 소개 및 설명 PDF
   - 제목, 한 줄 소개, 목표, 조작, 종료 조건, 실행 방법, 플레이 링크와 영상 링크를 포함한다.
4. AI 활용 기술 PDF
   - 사용 도구, 활용 방식, 주요 프롬프트·지시, 구조, 외부 에셋과 오픈소스 라이선스를 포함한다.
5. 팀원 역할 PDF
   - 이름, 담당 역할, 실제 구현 영역과 협업·분업 방식을 포함한다.

## 권리와 기록

- 주요 AI 도구 명칭과 활용 방식을 `submission/ai-usage/`에 지속적으로 기록한다.
- 생성형 AI, 오픈소스, 외부 API, 이미지, 폰트와 음향의 이용 조건을 확인한다.
- 타인의 저작물과 아이디어를 무단 사용하지 않는다.
- 출품작의 저작권과 지식재산권은 원칙적으로 참가자에게 귀속된다.
- 수상작은 NHN이 접수 시작일부터 1년간 홍보·결과 발표·아카이브 목적으로 이용할 수 있다.
- 수상 시 행사 종료일부터 4개월 동안 사업화·투자·퍼블리싱·공동 개발에 관해 NHN에 우선협상 기회를 제공한다.
- 팀대표자, 상금 배분, IP 지분, 포트폴리오 사용과 수상 후 의사결정 방식을 팀 내부 문서로 합의한다.

## 제출 검증

- 최소 Chromium 계열 브라우저 두 종류와 로그인하지 않은 새 세션에서 플레이 링크를 확인한다.
- 심사자는 별도 유료 라이선스 없이 플레이할 수 있어야 한다.
- 저장소, 플레이와 영상 링크는 심사 종료까지 접근 가능하게 유지한다.
- 현재 준비 상태는 `docs/PROJECT_STATUS.md`에서 관리한다.
