# 프로젝트 작업 현황

이 문서는 여러 작업 채팅이 긴 대화 기록을 다시 읽지 않고 현재 상태를 인수인계하기 위한 짧은 현황판이다.

## 관리 원칙

- `AGENTS.md`, `DESIGN.md`, `docs/GAME_SPEC.md`의 규칙과 기획을 대체하지 않는다.
- 브랜치, PR, 병합, 배포, 데이터 동기화 또는 제출물 상태가 바뀐 작업만 관련 행을 갱신한다.
- 완료된 세부 과정과 긴 로그는 반복해서 옮기지 않고 PR, 이슈 또는 관련 문서 링크로 연결한다.
- 추측한 진행률을 기록하지 않는다. 확인하지 않은 항목은 `미점검`으로 표시한다.
- 갱신 시각은 KST로 기록한다.

## 공통 GitHub·배포 인수인계

- GitHub 서비스 작업은 `C:\Program Files\GitHub CLI\gh.exe`를 기본으로 사용한다.
- 작업 시작 시 CLI 인증을 한 번만 확인하며, 브라우저 로그인과 CLI 로그인을 구분한다.
- UI 배포는 소스 수정, Web Release 갱신, 로컬 Web 확인, 고유 PCK, 원격 해시와 필요 시 Pages 실화면 확인을 하나의 완료 흐름으로 묶는다.
